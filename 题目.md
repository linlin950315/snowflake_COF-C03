## Q1　Shared disk 架构的缺点

What is one disadvantage of the shared disk architecture? Choose one correct value.
- A. When a node in the cluster fails data is reshuffled which can be an expensive process.
- B. The storage is potentially a single point of failure.
- C. Shared disk architectures cannot exist in the Cloud.
- D. There is a single source of truth.

<details><summary>答案</summary>

**B**

Shared disk architectures rely on a single shared storage device. If this goes down it can affect the whole systems ability to read and write data.（共享磁盘架构依赖单一的共享存储设备，一旦它出故障，会影响整个系统的读写能力。）

</details>

## Q2　Shared nothing 架构的缺点

What is one disadvantage of the shared nothing architecture? Choose one correct value.
- A. Avoids bandwidth and network latency limitations of shared disk architectures.
- B. Improved scaling over shared-disk architecture.
- C. Storage and compute is tightly coupled.
- D. Shared nothing architectures cannot exist on the Cloud.

<details><summary>答案</summary>

**C**

Storage and compute are usually co-located on the same physical machine, so increasing or decreasing one will typically increase or decrease the other.（存储和计算通常位于同一台物理机器上，因此调整其中一个通常会连带改变另一个。）

</details>

## Q3　Snowflake 为什么是 "cloud native" 产品

What makes Snowflake a "cloud native" product? Choose one correct value.
- A. Snowflake was developed by AWS.
- B. Snowflake ported existing "big-data" technologies on to the cloud.
- C. Snowflake was designed to make use of the unique capabilities of the cloud.
- D. Snowflake runs on a combination of cloud and on-prem infrastructure.

<details><summary>答案</summary>

**C**

Snowflake 从一开始就是为利用云的独特能力而设计的，不是把现有大数据技术搬到云上，也不是云与本地混合运行。

</details>

## Q9　对象容器层级顺序

The object container hierarchy exists in what order? Choose one correct value.
- A. Account -> Organisation -> Database -> Schema
- B. Database -> Schema -> Account -> Organisation
- C. Organisation -> Account -> Schema -> Database
- D. Organisation -> Account -> Database -> Schema

<details><summary>答案</summary>

**D**

An Organisation contains multiple accounts. An account contains multiple databases. A database contains multiple schemas.（一个 Organisation 包含多个 account，一个 account 包含多个 database，一个 database 包含多个 schema。）

</details>
